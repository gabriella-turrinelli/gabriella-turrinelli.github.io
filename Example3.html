Below I reproduce and then improve a chart from the Financial Times. The chart originally appears in an article titled "Taming the four horsemen of the infocalypse," which was published on 27 November 2025.

I then recreated the graph by generating a dataset using the original data from Graphite. One important thing that I noticed about this graph is that it contradicts the data to ink ratio concept described by Tufte. The lines both add to 100%, so there appears to be superfluous ink and colors that do not assist in telling the story of the data.

I removed the “Human” line as the two lines added to 100%, made the introduction of ChatGPT clearer, and adjusted the title and subtitle.

CC5: Accessing Data via API and Scraper

Below I have two graphs that demonstrate two different methods to access data.

The above chart is created using API. The base URL is https://api.worldbank.org/v2. The elements that are needed are the country or countries (country/gbr;eu), the indicator (indicator/NE.EXP.GNFS.ZS), the format (format=json), and the number of observations per page (per_page=1000). The data is returned as a json file and is mostly tidy. Each region or country had one observation per year. I had to restrict the data in Vega Lite as the initial years of data had missing values.

The full URL is: https://api.worldbank.org/v2/country/gbr;eu/indicator/NE.EXP.GNFS.ZS?format=json&per_page=1000
